
# ShopEase – Beauty E-Commerce Management System

## Project Description
ShopEase is a web-based beauty e-commerce management system designed to help administrators manage products, customer orders, customer information and sales performance.

## Main Features
1. Admin login and registration.
2. Dashboard with business summary.
3. Product management.
4. Order management.
5. Customer management.
6. Sales analytics and charts.
7. Responsive navigation and layout.

## Instructions for Testing
1. Open the website using Google Chrome.
2. Enter the demo administrator email and password.
3. Click Login.
4. Navigate through the dashboard sections.
5. Test adding, editing and deleting products.
6. Test searching and filtering products and orders.
7. Update order statuses.
8. View customer information and sales charts.

## Data Storage
The prototype uses browser localStorage to store sample products, orders, customers and registered demo accounts. sessionStorage is used for the login session.

## Project Limitation
This is an academic front-end prototype. It does not use a real database, server-side authentication or payment gateway. All sample business data is illustrative.

## Deployment
The project can be published using GitHub Pages.
